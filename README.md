# M10 OEE Analysis & Productivity Improvement

## Project Overview
This project focuses on evaluating the Overall Equipment Effectiveness (OEE) of Machine M10 using Microsoft Excel. The analysis uses 1,095 manufacturing shift records from 2025 to evaluate equipment availability, production performance, product quality, and downtime losses.

The objective is to identify major production losses, investigate potential root causes, and develop a data-driven improvement plan to enhance manufacturing productivity and operational efficiency.

## Tools & Technologies
- Microsoft Excel
- Advanced Excel Formulas
- KPI Analysis and OEE Calculation
- Data Validation
- Pareto Analysis
- Downtime Analysis
- Shift-wise and Product-wise Analysis
- Root Cause Analysis
- Fishbone Diagram and 5-Why Analysis
- Interactive Dashboard and Data Visualization

| KPI | Baseline Result |
|---|---:|

| Quality | 94.25% |

| Rejected Units | 37,907 units |

*Note: KPI percentages are calculated as averages of the 1,095 shift records.*

## Project Analysis

### 1. Baseline OEE Analysis
- Calculated Availability, Performance, Quality, and OEE.
- Evaluated equipment effectiveness using manufacturing shift data.
- Compared baseline performance against proposed improvement targets.

### 2. Downtime Analysis
- Analyzed downtime by cause, shift, and month.
- Evaluated downtime events and average downtime duration.
- Identified unclassified downtime as a major data-quality and investigation priority.

### 3. Pareto Analysis
- Ranked the four classified downtime causes.
- Identified breakdown, maintenance, and material shortage as the leading classified causes.
- Found that these three causes account for approximately 83.09% of classified downtime.

### 4. Performance and Quality Analysis
- Evaluated production performance across records and products.
- Analyzed rejected units and quality performance.
- Identified opportunities to reduce speed losses and quality losses.

### 5. Root Cause Analysis
- Investigated potential causes of breakdowns, maintenance delays, material shortages, setup losses, and unclassified downtime.
- Applied Fishbone and 5-Why analysis to structure problem investigation.
- Developed corrective and preventive improvement recommendations.

### 6. Productivity Improvement Plan
- Proposed preventive maintenance and condition-monitoring practices.
- Recommended material replenishment controls and standardized setup procedures.
- Suggested mandatory downtime reason codes and improved defect tracking.
- Developed an improvement roadmap with suggested owners and timelines.

### 7. Interactive Excel Dashboard
- Created a dashboard for monitoring key manufacturing KPIs.
- Added product, shift, and month filters.
- Presented OEE performance, production, rejects, and supporting visual analysis.

## Workbook Structure

The Excel workbook contains 14 worksheets:

1. `01_M10_Data` – Manufacturing shift records
2. `02_Data_Validation` – Data validation and supporting lists
3. `03_Baseline_OEE` – Baseline KPI calculations
4. `04_Downtime_Analysis` – Downtime by cause, shift, and month
5. `05_Pareto_Analysis` – Pareto ranking of classified downtime
6. `06_Performance_Analysis` – Production performance analysis
7. `07_Quality_Analysis` – Quality and rejection analysis
8. `08_Product_Analysis` – Product-wise performance
9. `09_Shift_Analysis` – Shift-wise performance
10. `10_Loss_Summary` – Availability, performance, and quality losses

12. `12_Improvement_Plan` – Recommended improvement actions
13. `13_Target_Analysis` – Target scenario and OEE improvement estimates
14. `14_Dashboard` – Interactive Excel dashboard

## Improvement Targets

The workbook includes an illustrative target scenario:

- Availability: 90%
- Performance: 88%
- Quality: 95%
- Target OEE: 75.24%

These are proposed targets, not achieved results. The scenario estimates an OEE improvement of approximately 5.52 percentage points over the baseline.
